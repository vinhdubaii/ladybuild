# ladybuild

Thử build [Ladybird](https://github.com/LadybirdBrowser/ladybird) cho Windows (native, Clang-CL, thử nghiệm) bằng GitHub Actions.

1. Chạy **1 - Survey Windows runner** để xem ổ đĩa, Visual Studio, Clang/CL, công cụ có sẵn.
2. Chạy **2 - Build Ladybird (Windows, experimental)** để build. Nếu thành công, tải `ladybird-windows` ở mục Artifacts.

Bản build Windows của Ladybird còn thử nghiệm nên có thể lỗi.
